# Sunum Büyüteci – Kullanım

## Başlarken
1. Projeksiyonu/TV'yi bağlayın, `Win + P` → **Uzat**.
2. `SunumBuyuteci.exe`'yi açın (kurulum gerekmez). Ekranlarda büyük numaralar belirir.
3. Sunum ekranını seçip **Başlat**'a basın. Küçük **kontrol penceresi** açılır (görev çubuğunda durur).
4. Sunum ekranında kendi ekranınızın kopyası görünür. Yakınlaştırınca sizin ekranınızda çerçeve çıkar.

## Kontrol penceresi
`[−] 200% [+]  |  Kilit  Tam ekran  |  Ayarlar`
- − / + ile büyütün, Kilit ile çerçeveyi sabitleyin, Tam ekran ile 1x ↔ son büyütme arasında geçin.
- Ayarlar: takip modu, fareyi bu ekranda tut, hep üstte, ekranı değiştir, kısayollar, çıkış.
- Arkada kalırsa görev çubuğundan tıklayın. ✕ uygulamayı kapatır.
- İzleyiciler bu pencereyi görmez. Fare üzerindeyken çerçeve yerinde durur.
- Düğmelerin üzerine gelince kısayolları yazar.

## Kısayollar (sol Alt ile; AltGr ile yazdığınız @ gibi karakterler etkilenmez)
| Kısayol | İş |
|---|---|
| Ctrl + Alt + Fare tekerleği | Yakınlaştır / uzaklaştır |
| Ctrl + Alt + ↑ / ↓ (veya numpad + / -) | Yakınlaştır / uzaklaştır |
| Ctrl + Alt + 0 | Tam ekran (1x) |
| Ctrl + Alt + K | Çerçeveyi kilitle / çöz (kilitliyken turuncu) |
| Ctrl + Alt + Q | Çıkış |

Simgeye çift tık: 1x ↔ son yakınlaştırma. Sağ tık menüsünde takip modu, fare kilidi, ekranı değiştir ve kısayollar var.

## PowerPoint ile
Uzat modunda PowerPoint slayt gösterisini kendiliğinden sunum ekranına gönderir. Sunumu kendi ekranınızda
açın: **Slayt Gösterisi → Monitör → Birincil Monitör** ve **Sunucu Görünümünü Kullan** işaretini kaldırın.
Böylece sunum sizin ekranınızda oynar, izleyiciler büyüteçli kopyasını görür.

## Bilinen kısıtlar
- Yönetici izni (UAC) pencereleri ve korumalı videolar (Netflix vb.) sunum ekranında siyah görünür.
- Bildirimler sizin ekranınızda göründüğü için sunum ekranında da görünür; sunum öncesi "Rahatsız etmeyin"i açın.
